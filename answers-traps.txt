## **答案整理**

### 1. 参数寄存器
**问：哪些寄存器存放函数参数？哪个寄存器存放 `13`？**

在 RISC-V 中：
- `a0` = 第1个参数  
- `a1` = 第2个参数  
- `a2` = 第3个参数  
- ... 依此类推

从您提供的汇编代码：
```
24:   4635                 li      a2,13      # 第三个参数 = 13
26:   45b1                 li      a1,12      # 第二个参数 = 12
```
- `13` 放在 **`a2`** 寄存器（第三个参数）
- `f(8)+1` 的计算结果 `12` 放在 **`a1`** 寄存器（第二个参数）
- 第一个参数（格式字符串地址）后面加载到 `a0`

**答案：**
```
函数参数依次存放在 a0, a1, a2, a3, a4, a5, a6, a7 寄存器。
13 存放在 a2 寄存器。
```

### 3. printf 的地址
**问：printf 函数位于哪个地址？**

从调用 `printf` 的指令：
```
30:   00000097           auipc   ra,0x0
34:   5f6080e7           jalr   1526(ra) # 626 <printf>
```
- `auipc ra,0x0` 将当前 PC（0x30+4=0x34？实际上auipc用法要仔细算）加载到 ra，高位偏移为0
- `jalr 1526(ra)` 将 ra 加上 1526 后跳转
- 注释 `# 626 <printf>` 表明目标地址是 **0x626**

实际上，我们通常看注释给出的地址：`# 626 <printf>`  
这表示 `printf` 函数在地址 **0x626**。

**答案：**
```
printf 函数的地址是 0x626。
```

### 4. 输出结果分析
**问：运行以下代码的输出是什么？**
```c
unsigned int i = 0x00646c72;
printf("H%x Wo%s", 57616, &i);
```

**分析：**
- `57616` 十进制 = `0xE110` 十六进制
- `%x` 会输出 `e110`（小写十六进制）
- `i = 0x00646c72` 在内存中按字节（小端序）存储为：
  ```
  地址低位 → 高位
  72 6c 64 00  (因为 0x72='r', 0x6c='l', 0x64='d', 0x00='\0')
  ```
- `%s` 会从 `&i` 开始打印字符直到 `\0`，所以打印出 `"rld"`（因为小端序先读最低字节 0x72='r'）

**输出：**
```
He110 World
```

**答案：**
```
输出是 "He110 World"。
因为 57616 = 0xe110，而 i 在小端序下存储为字节序列 72 6c 64 00，
%s 会解读为字符 'r' 'l' 'd' 然后遇到空字符结束。
```

### 5. 大端序调整
**问：如果 RISC-V 是大端序，要得到相同输出，i 应设为什么值？57616 需要改吗？**

- 大端序下，整数 `0x00646c72` 在内存中存储为：
  ```
  地址低位 → 高位
  00 64 6c 72  (与书写顺序一致)
  ```
  这样 `%s` 会先读 `0x00` 即空字符，所以什么都不输出。

- 要输出 `"rld"`，需要让内存中字节顺序为 `72 6c 64 00`，所以 `i` 应设为 `0x726c6400`（大端序书写值）。

- `57616` 是整数，大端序和小端序对 `%x` 没有影响，因为 `printf` 从寄存器读取整数值，而不是内存字节序。所以 `57616` 不用改。

**答案：**
```
如果 RISC-V 是大端序，应将 i 设为 0x726c6400。
这样在内存中存储的字节顺序就是 72 6c 64 00（大端序高位在前），
%s 才能打印出 "rld"。57616 不需要改变。
```

### 6. 格式化字符串漏洞
**问：下面的代码会打印什么？为什么？**
```c
printf("x=%d y=%d", 3);
```

**分析：**
- 格式字符串需要两个 `%d` 参数，但只提供了一个 `3`。
- `3` 会放在 `a0`（第一个参数是格式字符串地址）之后，即 `a1` 存放 `3`。
- 第二个 `%d` 会从 `a2` 寄存器读取值，但 `a2` 里是调用前的残留数据（不确定值）。
- 所以 `y=` 后面会打印一个不确定的整数值（可能是栈上或寄存器中原有的值）。

**答案：**
```
会打印 "x=3 y=?"，其中 ? 是一个不确定的值（可能是调用前的 a2 寄存器内容）。
因为 printf 期望两个整数参数，但只传入了一个，第二个 %d 会读取未初始化的寄存器 a2 的值。
```
